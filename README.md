# HELIX 계산기

DAI·원화·Anubis LGNS 진입과 AiLGNS 재소각 경로를 비교하는 개인용 시뮬레이터입니다.

**[계산기 열기](https://spaceechoboy.github.io/helix-simulator/)**

- 3·6·12개월 수령액과 현금 수익률
- POWER·누적 보상 가치·실제 현금 그래프
- 6개월·1년·2년·3년 재소각 중단 시점 비교
- 공개 RPC와 시세 API 조회, 출처·조회 시각 표시

## 실행 및 검증

Node.js 22 이상, 외부 패키지 설치 없이 실행합니다.

```sh
npm test
npm run build
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

`src/`는 소스, `dist/`는 단일 HTML 빌드, `docs/`는 GitHub Pages 게시본입니다. 수정 후 빌드하고 `dist/`의 파일을 `docs/`에 반영합니다.

## 계산 가정

투자 권유가 아닙니다. 현재 가격·배출 조건·수수료가 유지된다는 가정이며 미래 수익이나 실행 가능성을 보장하지 않습니다. LGNS·AiLGNS 소각 한도는 별도 표시하고 가정 계산에서는 제외합니다. LGNS 소각 인정액과 시장 평가액은 다르며 배율 해석에는 미검증 사항이 있습니다. 받은 보상의 평가액과 실제 회수한 현금도 다릅니다.

외부 API의 CORS·접속 제한으로 실시간 조회가 실패할 수 있습니다. 저장 데이터는 2026-10-23 관측 표본으로 최신값이 아니며 화면에 상태를 표시합니다. 지갑 연결·서명·거래 전송 기능은 없습니다.

## 이미지

토큰 심볼은 기존 Anubis Guide 자산에서 가져와 HTML 내부에 포함했습니다. 관련 상표·이미지의 권리는 각 권리자에게 있습니다.


## 실시간 기준 (2026-10-26)
첫 계산 전 RPC/API·시장 시세를 조회하고 60초마다 자동 반영합니다. 필수 값이 조회되지 않거나 5분을 넘으면 결과를 보류하며 저장 가격으로 대체하지 않습니다. 코드/구현 관측 기준은 `src/protocol-baseline.js`에 기록합니다. 변경 감지는 동작 또는 보안 인증이 아닙니다.

검증 범위와 미검증 프로토콜 가정은 [VALIDATION.md](VALIDATION.md)를 확인하세요. 최신 입력을 사용하는 조건부 모형이며 실거래 수익 보장이 아닙니다.
