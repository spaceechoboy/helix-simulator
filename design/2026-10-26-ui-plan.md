## Claude Opus 5.5 교차 검토 반영 (1차)
공개 계산기 소스만 읽도록 제한한 CLI 검토. 실효 claude-opus-5-5, 읽기 전용, 비용 도구정가 $1.0654928(구독 청구 아님).
발견한 설계 결함과 채택 결정:
- 기준표는 항상 고정3년 ‘매일 현금화’ 장부에서3/6/12/18/24개월을 추출한다. 최적화 기간은 별도 상태로 분리한다. 기간 변경 때문에 기준표가 ‘기간 밖’으로 변하지 않음.
- 최적화는 기준표를 덮어쓰지 않는다. 선택기간의 전략 결과를 별도 비교 영역에 추가하고 그래프도 ‘매일 받기/전환 전략’ 명시 선택으로만 변경한다. 첫3개월 현금0을 기본성과처럼 오인하지 않게 함.
- 사용자 표시 ‘실제 현금’은 ‘현금 인출(계산)’으로 정정. 계산된 값에 실제 지급처럼 보이는 표현 금지. ‘순이익’은 ‘현금 순손익’, ‘원금회수’는 ‘총투입 회수일(계산)’과 원금기준 보조설명.
- 차트 동일시리즈의 범례/선 색상 토큰 공유. 보상 점선은3:1이상, 고정날짜는 데이터갱신 후 동일날짜가 있으면 보존. 손가락8px이상 이동은 스크롤로 간주, pointerup의 짧은 탭만 고정.
- 시각 tooltip aria-hidden, 키보드/고정에만 별도 polite announce(300ms). 모든 주동작44px, 최소24px.
- 입력 반영 중 결과는 클릭불가 skeleton으로 공간 유지. 무효/만료 시 과거숫자는 숨김. ‘흐리게 남긴 오래된 수치’는 채택하지 않음.
- LIVE와 실거래 산식 검증은 분리. 1LGNS→2POWER를 먼저 쓰고 비교원금1DAI는 별도 문장.
현재 구현의 위 UX 결함은 이번 ‘설계 먼저’ 범위에서 해결 명세를 작성했으며, 운영 코드가 이미 고쳐졌다고 보고하지 않는다.
